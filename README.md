# Лабораторна робота № 3

Жуков Михайло Володимирович · варіант № 2.
Чисельні методи розв'язання задачі Коші для звичайних диференціальних рівнянь.

## Запуск

Розпакуйте весь комплект і відкрийте **index.html** у Chrome або Edge.
Сервер, інтернет і встановлення пакетів для самої програми не потрібні.
Стек: JavaScript, HTML/CSS, Canvas. Перевірено у Windows 11.

Варіант: y′=-2y, y(0)=3, x∈[0;2], точний розв'язок 3exp(-2x).
Перемикачі обирають задачу, n=5/10/20 та метод анімації. Кнопки
«Відтворити», «Пауза», «Наступний крок», «На початок» і повзунок
керують реально збереженими кроками. Стадії РК4 показано окремими
точками й відрізками нахилів та таблицею k1..k4.

## Власні функції

Розкрийте «Власна функція та початкові умови». Дозволено арифметику
`+ - * / ^`, дужки, `x`, `y`, константи `pi`, `e`, функції
`sin cos tan exp ln log sqrt abs atan asin acos`.
Наприклад, `x+y` та точний розв'язок `2*exp(x)-x-1` для y(0)=1.
Множення явне: `2*y`; десятковий роздільник - крапка.
`^` - піднесення до степеня, правоасоціативне; `-2^2` дорівнює -4.
Поле точного розв'язку можна залишити порожнім. Тоді похибка недоступна.
Якщо еталон задано, перевіряється початкова умова; перевірка всього
диференціального рівняння для довільної введеної формули не виконується.

n має бути цілим від 1 до 10000. Зворотний напрям інтервалу дозволено;
нульову довжину та нескінченні значення відхилено. Помилковий ввід не
замінює останню коректну задачу. Вузлова таблиця обмежена 201 початковим
вузлом і кінцевою точкою для великих n; CSV містить усі вузли.

## Дослідження

- Галерея: 6 графіків початкового варіанта n=5/10/20, незалежно від власного вводу.
- Порядок: відношення максимальних вузлових похибок і log2(ratio).
- Стійкість: y′=-20y, y(0)=1, [0;1], метод Ейлера; кінцеві значення -243, 1, 0.
- Бонус: Лотка–Вольтерра, u′=u-0.1uv, v′=0.075uv-1.5v;
  u(0)=10, v(0)=5, t∈[0;30]. РК4, фазовий портрет, чисельності та інваріант.

Кнопки CSV зберігають UTF-8 з BOM і роздільником `;`.
Для основної задачі доступні точні значення й похибки кожного методу.

## Тести й вимірювання

Потрібен Node.js 20 або 24; локально перевірено v24.14.0.

```text
node --test tests/*.test.js
node scripts/order-check.js
node scripts/metrics.js
```

Альтернативно: `npm test`, `npm run order`, `npm run metrics`.
У PowerShell із забороненими ps1 використовуйте `npm.cmd`.

Початковий невдалий запуск до реалізації ядра - results/tdd_initial.txt.
Критичний тест РК4: 40→80 дає ratio≈16.682 і p≈4.060.
На грубій сітці 5→10 ratio≈22.306; це не доводить помилку алгоритму.
Негативний тест навмисно підміняє h/2 на h у y2,y3 та виявляє порядок ≈1.

Час у звіті: медіана 9 пакетів по 200 розв'язувань після 30 прогрівів,
поділена на 200; без запису історії стадій, DOM та графіків. Повернення
вузлів і обчислення похибок включено. Результати в results/metrics.json.
У браузері показано час одного запуску з кадрами, тому він відрізняється.

Необов'язкова браузерна перевірка (потрібен встановлений Chrome):

```text

node scripts/browser-check.js
```

## Структура та Strategy

| Файл | Призначення |
|---|---|
| js/expr.js | Парсер рекурсивного спуску без eval/new Function |
| js/ode.js | OdeMethod, EulerMethod, HeunMethod, RK4Method, MethodRegistry, CauchySolver |
| js/chart.js | Canvas Chart та автоматичні межі |
| js/app.js | Application: події, таблиці, анімація та експорт |
| tests/ | Парсер, методи, порядок, стійкість, мутація, векторний РК4, масштаб |
| scripts/ | Вимірювання, тест порядку, перевірка браузера |
| docs/ | ТЗ, методологія, діаграми |
| results/ | JSON/CSV, протоколи, знімки |

Нова стратегія реалізує `step(f,x,y,h)` і повертає `{y,stages}`.
Її додають через `Ode.registry.register(instance)` до створення Application.
Опції інтерфейсу та розрахунки будуються з `registry.list()`; солвер і
розмітку для нового методу змінювати не потрібно. Для вже відкритого
інтерфейсу є `odeApp.refreshMethods()` та `odeApp.recalculate()`.

JavaScript Number, фіксований крок, без адаптивного контролю похибки.
Гарантії існування й єдиності для довільного вводу не перевіряються.

відліки та всі чисельні вузли/стадії, але не доводить глобальні екстремуми
довільної функції між відліками. Нулі на логарифмічній осі не малюються.
