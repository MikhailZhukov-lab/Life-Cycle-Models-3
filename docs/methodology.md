# Розвиток Agile у ЛР № 3

У ЛР № 2 використано ітеративний Agile. Для ЛР № 3 додано практики XP:
TDD математичного ядра, регресійні тести, розширювані стратегії та CI.

1. Вимоги, приклади й тести написано до js/expr.js та js/ode.js. Перший
   запуск завершився помилками відсутніх модулів: results/tdd_initial.txt.
2. Реалізовано парсер, стратегії та контекст CauchySolver. Початковий набір
   із 52 тестів пройшов; експерименти дали фактичні таблиці похибок.
3. Додано Canvas, анімацію, власні функції, бонус і ще 6 регресійних тестів.
4. Браузерний набір перевірив 32 сценарії, включно з додаванням нової стратегії.
5. Підготовлено звіт, дані, AI-журнал та локальну історію Git.

Критерій готовності локальної ітерації: тести проходять; числові дані
відтворюються; зміни інтерфейсу перевірено в браузері. GitHub Actions
виконав перевірки успішно на Node.js 20 і 24; доказ: results/ci_status.json.
